# Changelog

## 0.1.0
- First version: a SIP doorbell tile with the live phase, the caller, a connected timer and a tap that runs the toggle script.
- A ring popup with **Answer** and **Decline** writes the command helper, on by default and switchable in Settings.
- Built for plugin API 0.18, the lowest with the popup and action features used here; the tile sizes are 1x1 to 2x2.
