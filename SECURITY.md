# Security policy

This card puts a SIP account in a browser. Read
[docs/SECURITY.md](docs/SECURITY.md) for the threat model and mitigations.

## Reporting

Please open a **private security advisory** on GitHub
(https://github.com/Babo96/tessera-sip-card/security/advisories/new) for:

- a credential leak,
- a way to make the card send media or requests somewhere unexpected,
- a cross-site scripting issue in the card or its editor.

Do not post secrets, SIP passwords, TURN credentials or full debug logs in a
public issue.

## Supported versions

Only the latest release on `main` is supported. There is no LTS branch yet.
